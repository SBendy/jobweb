## CapService — статический сайт

Все редактируемые **тексты и картинки** только в **`content/`** — у каждого подраздела своя папка и при необходимости вложенная **`assets/`** (см. `content/README.md`). В корне проекта нет общих каталогов `assets` или `images` — только `index.html`, `styles.css`, скрипты, `pages/` и `content/`.

Подключение скриптов на главной: `home-content.js` → `app.js`.
